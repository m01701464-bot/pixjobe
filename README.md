# База клиентов

Android-приложение для поиска бизнесов Шымкента без сайта и ведения базы для холодных звонков.

- Поиск по категориям через OpenStreetMap (бесплатно) или Google Places API (нужен свой ключ).
- Фильтр «нет сайта» / «только соцсети», сортировка по числу отзывов.
- Кнопки «Позвонить» и «WhatsApp» с готовым сообщением, статусы, заметки, дата перезвона.
- Выгрузка базы в CSV.

APK собирается автоматически: вкладка **Actions** → последний запуск → **Artifacts** → `baza-klientov-apk`.
