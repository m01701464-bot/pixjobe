Ключ Google Maps

  1. Открой console.cloud.google.com и создай проект.
  2. Привяжи платёжный аккаунт. Карта нужна для проверки, но небольшой объём поиска бесплатный каждый месяц.
  3. В «APIs & Services → Library» включи Places API (New).
  4. В «Credentials» нажми «Create credentials → API key», скопируй ключ сюда.
  5. В настройках ключа ограничь его только Places API, чтобы им не воспользовались другие.

Запросов к Google в этом месяце: 0. Один поиск по одной категории тратит 1–3 запроса, по районам до 15.
